# 海外 POI 精度回归样例

## 1. 文档目的

本样例集用于验证海外旅行规划场景下的 POI 召回、坐标回填、地图渲染与降级说明。重点不是追求一次生成的文案多漂亮，而是确认点位不会空、不会明显错位、不会把海外地点匹配到错误城市或国家。

## 2. 验收口径

每条样例至少检查以下结果：

- 行程是否生成成功。
- 地图是否出现 marker。
- marker 是否落在目标城市或目标岛屿附近。
- fallback 是否触发，触发后是否写入 assumptions 或可观察日志。
- evidence 是否保留 provider/source 信息。
- 编辑一个 slot 后，新地点是否有新坐标，且不会沿用旧地点坐标。

## 5. 人工判定规则

### 5.1 通过

- marker 位于目标城市或目标岛屿合理范围内。
- 同名 POI 匹配到正确国家和城市。
- fallback 触发时仍能显示 marker，并且 assumptions 中能解释“坐标为近似位置”或类似含义。
- 编辑后新 slot 不携带旧 slot 的 evidence、费用、坐标或风险字段。

### 5.2 需要修复

- 海外地点被匹配到中国城市。
- 同名地点跨国家误匹配，例如“环球影城”匹配到美国而不是大阪。
- 地图 marker 全部集中在城市中心，但文案声称已找到具体地点。
- Provider 超时后没有降级说明，用户无法理解为什么点位粗略。
- 编辑 slot 后仍显示旧地点坐标。

## 7. 后续自动化方向

后续可以把本文件中的样例固化为半自动回归：

- 请求后端生成结构化行程。
- 抽取每个 slot 的 `location.lat/lng`。
- 使用目标城市 bbox 做粗校验。
- 对 fallback 或无 evidence 的 slot 输出失败报告。

自动化前先保留人工抽检，因为海外 POI 同名、多语言别名和景区边界会带来误判。
